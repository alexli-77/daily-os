Focus on today.

Built on the ideas of The 7 Habits of Highly Effective People, Daily OS draws on data sources you choose and breaks your five-year, annual and quarterly OKRs into plans for each cycle and each day. It runs on your own Mac, so your data and tasks stay in your hands, and regular planning and reviews keep work and life in order.

Install guide View on GitHub

Install from source for now: Node.js 22+, Feishu (lark-cli or a custom app), and Codex CLI or an OpenAI API key.

What it does for you each day

Plans are drafts, reviews are grounded in what you did, and nothing is written back without asking.

Builds today's plan

Pulls in Feishu calendar and tasks, GitHub issues assigned to you, Linear work and local notes, schedules them by estimate, and marks the one thing that matters most today (MIT).

Reviews the day

Compares the plan with what you checked off and sorts it into done, progressed and untouched. Unfinished items move to tomorrow instead of quietly disappearing.

Three-level OKRs and cycle reviews

Five-year North Star, annual and current OKRs live on your Mac. A plan for next week every week; every two weeks, KR progress, written back only after you confirm in Feishu.

Works inside Feishu

Send commands and press cards in chat: note something down, check status, or ask for a plan, review or weekly report right now.

Native macOS client

Today, cycles, OKRs, past days and a menu bar item, reading live data from the service on your Mac. Light and dark.

Read-only team view

Each teammate runs Daily OS on their own machine. Their plans for today show up read-only; nobody can edit anyone else's.

Every day is kept

Past days keeps each day's final plan, how far you got, and the evening review. Read-only.

  • Done, partly done, carried over and untouched are recorded separately
  • Each review line carries a reason, such as "PR merged" or "half the suite ran, UI cases left"
  • These records feed the weekly review and OKR progress

How it works

Set it up once. After that, plans arrive in Feishu and you reply with progress.

  1. Install the service on your MacClone the service repo, run npm ci, then npm run setup and connect Feishu and the sources you want.
  2. Try it without sendingRun npm run plan -- --no-send to see the plan it would send. Turn on real delivery once you like it.
  3. Install it as a background servicelaunchd starts it at login. Jobs missed while the Mac slept are caught up the same day.
  4. Use it from Feishu every dayA plan in the morning, progress during the day, a review in the evening, next week's plan at the weekend.

FAQ

What do I need to run Daily OS?

A Mac, Node.js 22 or later, a logged-in Codex CLI (or an OpenAI API key), and either a logged-in lark-cli or a Feishu custom app. Sending commands and pressing cards inside Feishu chat needs the custom app's App ID and App Secret.

Where does my data go?

The service runs on your own Mac. Config, memory and tokens live in git-ignored files on your machine. When it builds a plan, the relevant content goes to the model you configured (Codex CLI or OpenAI API), and the output goes to your own Feishu.

Is it free?

Yes. The service is open source under AGPL-3.0 and the macOS client under MIT.

Does it support Windows or the web?

macOS only for now. The service ships a local browser console, and an iOS client is in development.
